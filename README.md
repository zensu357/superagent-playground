# Superagent Playground

A test repository for the **DeepSeek Super-agent**: a scratch space for exercising the agent's end-to-end GitHub workflow — opening issues, creating branches and pull requests, and reviewing changes — without touching real projects.

## What it is for

- Trying out the agent's issue-to-pull-request workflow.
- Testing review and automation behavior on throwaway changes.
- Serving as a sandbox for experiments; nothing here is production code.

## Notes

This repository exists purely for testing. Changes may be reverted or rewritten at any time.
